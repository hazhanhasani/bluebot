# Blue Panel Android Client

First-party Android client for BlueBot customers. Users sign in with credentials generated by the Telegram bot and connect to their active Xray-compatible subscriptions without copying subscription links into third-party applications.

## Stack

- Kotlin + Jetpack Compose
- Android `VpnService`
- Xray-core through the official `XTLS/libXray` Android AAR
- BlueBot Client API (`/api/client.php`)
- Android Keystore for bearer-token encryption at rest

## User flow

1. User sends `/app` to BlueBot and receives an app username/password.
2. User signs in to Blue Panel on Android.
3. The app retrieves only subscriptions owned by that BlueBot user.
4. User taps **Connect**.
5. The app loads the connection profile in memory and passes the Android TUN file descriptor directly to Xray-core.

The UI never displays subscription URLs or share links.

## API endpoint

The default API endpoint is:

```text
https://bot.blluepanel.ir/api/client.php
```

Override it without editing source:

```bash
gradle -p android-client :app:assembleDebug \
  -PBLUEBOT_API_BASE=https://example.com/api/client.php
```

## Build

Requirements:

- JDK 17
- Gradle 9.6+
- Android SDK 37

```bash
gradle -p android-client :app:assembleDebug
```

The build downloads `libxray-android.zip` from the pinned official release, verifies its SHA-256 digest, and extracts the AAR locally. The binary is intentionally not committed to this repository.

## Security notes

- Passwords are hashed server-side and never recoverable.
- Login sessions are device-bound and can be revoked by rotating the app password from BlueBot.
- Bearer tokens are encrypted with Android Keystore.
- Cleartext HTTP is disabled by the Android manifest.
- Subscription payloads are kept in memory and are not intentionally persisted by the app.
- Panel administrator credentials are never returned by the Client API.

## Supported service family

The first release targets Xray-compatible subscriptions from BlueBot panel adapters such as Marzban, Marzneshin, Hiddify and X-UI variants. Unsupported services remain visible but cannot be connected from the Android client.

## Release status

`0.1.0` is the MVP client. Production signing, Play Store metadata, crash reporting, device/session management UI and broader protocol regression testing belong to the next release milestone.
