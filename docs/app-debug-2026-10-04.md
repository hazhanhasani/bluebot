  attempts, and preserve the final connection error after service destruction.
  Disconnect/reconnect no longer lets a canceled attempt stop a replacement
  connection. Network preparation does not hold the native lifecycle lock.
- Recover expired sessions using HTTP 401 and missing-token state, including
  errors returned as non-JSON responses. Dashboard, store, and VPN monitoring
  return to login and clear the previous account's state.
- Let mobile accounts select another purchased service. Selection survives list
  refreshes and stays locked while connecting or connected.
- Ignore late camera-provider, scan, gallery, and permission results after the
  QR overlay closes; close camera image proxies on success and failure paths.
- Declare camera/autofocus hardware optional, preserving installation and
  gallery/manual entry on devices without a back camera. Add the required
  CameraX image API opt-in found by Android lint.
- Preserve QR payload/password bytes in client JSON requests, so query-string
  ampersands do not change service fingerprints or credentials.
- Normalize Persian and Arabic digits by whole UTF-8 characters in SMS OTP and
  numeric SMS fields. OTP attempt limits, expiry and single-use behavior remain
  enforced.

## Mini App corrections

- Signed launch identity takes priority over another account's cached bearer;
  cached React sessions restore only for the current Telegram launch user.
  Independently valid bearer sessions remain compatible with expired launch data.
- Account, catalog and custom-sales handlers reuse the authenticated user,
  including initData-only launches and stale bearer caches.
- Treat catalog/product permission failures separately from authentication
  failures; ordinary HTTP 403 business errors do not clear a valid session.
- Read browser storage properties inside the protected operation, prefer the
  active in-memory token, and clear storefront credentials on logout.
- Resolve startup assets and storefront API requests independently of nested
  SPA routes, preventing missing scripts/catalog requests on service pages.
- Apply the customer's discount to custom price quotes using the checkout
  formula, so wallet eligibility agrees with the amount actually charged.
- Update the Mini App build/cache version to `0.2.7`. Keep the compiled entry's
  canonical URL and existing JS/CSS revalidation headers.
